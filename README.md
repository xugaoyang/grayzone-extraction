# 灰域行动 · GRAYZONE

一个原创的 3D 单人战术搜打撤游戏。借鉴战术撤离类游戏的玩法节奏，采用紧凑港区，具有从出战、搜刮和交战，到撤离结算、基地升级、再次出战的完整循环。

在线游玩：https://xugaoyang.github.io/grayzone-extraction/ 。公开源码：https://github.com/xugaoyang/grayzone-extraction 。

## 启动

双击本目录的 **Start-Game.cmd**。启动器会开启本地服务并打开浏览器。第一次安装依赖需要网络，依赖和构建准备好后，游戏完全在本机运行，无需账号或外部资源服务。运行环境为 Node.js 20.19+ 或 22.12+，建议使用新版 Chrome / Edge 并开启硬件加速。

默认地址为 http://127.0.0.1:4173 ，占用时会尝试后续端口。关闭浏览器后服务器仍在后台，可双击 **Stop-Game.cmd** 停止由启动器启动的服务。重复启动会优先复用已记录的地址或已开启的游戏服务。

## 一局怎么玩

1. 在基地选择出战装备。轻装侦察始终免费，战术与重装装备在出战时支付费用。
2. 部署到港区南侧。前方有安全的入门物资箱，靠近后长按 **E** 搜索。每个首次搜索的箱子补充 24 发备弹，并有机会获得医疗包。
3. 搜索港区其他物资点，击败巡逻守卫后也能搜索战利品。金色高价值箱通常位于守卫附近。枪声会吸引附近敌人；掩体可阻挡双方子弹，蹲行更不容易被发现。
4. 背包有重量限制。按 **Tab** 查看价值与容量，可丢弃低价值物资，丢弃物可重新拾取。
5. 按 **M** 找到东北侧的绿色撤离区。进入绿色圆圈，长按 **E** 坚守 6 秒。松开、移动或受到攻击会中断，需要重新开始。在撤离圈内看向脚边的物资箱可优先搜索；看向前方即可呼叫撤离。
6. 成功撤离后，物资自动兑换资金，并结算击败奖励与合约奖励。使用收益强化护甲、升级武器或扩容背包，再次出战。

每局行动窗口 **8 分钟**。死亡、超时或主动放弃都会损失本局携带物资和已支付的出战装备费用；基地资金与永久升级保留。免费装备保证资金耗尽后仍能重新出发。暂停、地图和背包界面都会暂停单人游戏。

## 操作

| 按键 | 操作 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 | 观察 / 瞄准 |
| 左键 / 右键按住 | 射击 / 瞄准 |
| 左 Shift / C 按住 | 冲刺 / 蹲行 |
| R | 换弹 |
| B | 突击步枪切换单发 / 自动 |
| E 按住 | 搜索 / 撤离 |
| F | 使用医疗包，恢复最多 65 生命 |
| Tab | 背包 / 丢弃物品 |
| M | 战术地图 |
| Esc | 暂停 / 释放鼠标 |

点击“继续行动”恢复鼠标锁定。冲刺期间不能开火；治疗会被攻击、射击或冲刺中断。头部命中造成额外伤害。设置中可调整总音量、独立背景音乐音量、鼠标灵敏度和画质。

三种出战装备分别携带不同武器：免费 C9 冲锋枪使用 24 发弹匣，射速快、后坐低，近距离更有效；AR4 突击步枪使用 30 发弹匣，按 B 切换单发与自动；DMR7 精确步枪使用 18 发弹匣，具有更高倍率瞄准和更强后坐，每次点击左键射击一发。三者的枪型、枪声、换弹时长、枪口火光、弹壳和烟雾均不同。精确步枪远距离威力保留更好，冲锋枪远距离伤害下降更明显。

守卫拥有视野方向与反应时间，会观察、缓慢转身、抬枪短点射，并在交战或受击时侧移、寻找掩体。动作包含呼吸、转头、眨眼、膝肘弯曲、脚掌落地、受击踉跄和渐进倒地；手部随持枪姿态移动。玩家也有步行重心、换弹握持和不同武器后坐反馈。

点击界面后启用原创环境配乐。基地与探索使用舒缓的氛围音乐，附近守卫进入警戒后叠加紧张节奏，呼叫撤离时加入倒计时层。暂停时音乐淡出，切换到后台后停止播放，回到页面继续行动即可恢复。音乐与港口风声、海浪声均由 Web Audio 在本机合成，无需下载外部音频。

## 内容与边界

- 约 100 × 100 米的港区地图：南侧补给区、仓储区、集装箱区、北岸撤离区。
- 午后天空、薄云、柔和阴影、波动海面，带表面纹理的仓库、道路与集装箱；战术地图显示分区、建筑轮廓与撤离参考路线。
- 平滑人体轮廓、迷彩服、头盔、战术护甲与装备袋；步枪包含瞄具、导轨、枪托、弹匣与握持双手，支持呼吸摆动、后坐与换弹姿态。
- 12 个场景物资点、8 名 AI 守卫；巡逻、听觉警戒、追踪、射线视野与掩体碰撞。
- 3 类装备、3 项永久升级各 3 级、8 类可搜集物资。
- 循环回收合约、重量背包、战斗音效、战术地图与结果账单。
- 本地浏览器存档保存资金、升级、统计与合约进度。不保存正在进行的战局。刷新页面视为离开当局，已支付装备费用不退还。
- 当前是可玩的单人 PvE 版本；不包含联网联机、真人对战、大型开放地图或商业游戏素材。

存档键为 `grayzone-extraction.profile.v1`，设置键为 `grayzone.settings`，存储在该浏览器、该地址的 localStorage 中。不同浏览器或端口使用各自的存档；清除站点数据会重置进度。建议一直使用启动器打开的同一地址。

## 开发

### GitHub Pages 发布

游戏可以作为静态网站发布到 GitHub Pages，玩家无需安装 Node.js，使用浏览器即可游玩。Vite 构建使用相对资源地址，兼容 `github.io` 的项目子目录。

仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。`.github/workflows/pages.yml` 会在提交到 `main` 后自动安装依赖、运行逻辑测试、构建并发布，也可在 Actions 页面手动触发。

GitHub Free 账号使用 Pages 时，承载网站的仓库需要公开。游戏的资金与升级仍保存在玩家自己的浏览器中，不会上传到 GitHub。线上地址与本地地址使用各自独立的存档。

### 本地开发命令

```sh
npm install
npm run dev
npm test
npm run test:browser
npm run test:combat
npm run build
npm start
```

`npm run test:browser` 需要开发服务器在 5173 端口运行，以及本机已安装 Chrome 或 Edge。可通过 `BROWSER_PATH` 指定 Chromium 可执行文件，`GAME_URL` 指定开发服务器地址。测试使用隔离的浏览器上下文，不修改日常浏览器存档；调试入口只存在于开发构建中，生产构建不包含它。

修改源码后运行 `npm run build` 更新正式版本。技术栈为 Three.js + Vite，全部 3D 模型、界面与音效由代码生成。

| 文件 | 用途 |
| --- | --- |
| src/main.js | 游戏循环、输入、AI 战斗、搜刮、HUD 与页面流程 |
| src/world.js | 港区地图、材质、天空与海面动画 |
| src/models.js | 士兵、战术装具与第一人称武器模型 |
| src/actor-animation.js | 人体关节、持枪双手、步态与受击动作 |
| src/weapons.js | 三种武器的射击模式、手感、距离伤害与特效配置 |
| src/combat-effects.js | 弹壳物理、枪口烟雾、曳光与命中碎屑 |
| src/navigation.js | 碰撞滑动、网格连通性与寻路 |
| src/economy.js | 装备、升级、随机战利品、结算与存档 |
| src/audio.js | Web Audio 程序化音效、环境声与动态配乐 |
| src/style.css | 中文战术界面与响应式布局 |
| tests/ | 经济、碰撞、地图可达性与浏览器流程验证 |

本项目的名称、界面、地图、角色和程序化资产均为原创简化实现，未使用《三角洲行动》的代码或美术资源。
